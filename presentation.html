Common activation functions

  • Sigmoid: σ(z) = 1 / (1 + e⁻ᶻ)
  • Tanh: (eᶻ − e⁻ᶻ) / (eᶻ + e⁻ᶻ)
  • ReLU: max(0, z) ← most used today
  • GELU: used in Transformers

Why non-linearity?

Without activation functions, stacking layers is equivalent to a single linear transformation — no matter how deep the network.

🔄 Backpropagation

The engine behind all neural network training

Backprop applies the chain rule of calculus to efficiently compute the gradient of the loss with respect to every parameter in the network.

∂L/∂wᵢ = ∂L/∂ŷ · ∂ŷ/∂zᵢ · ∂zᵢ/∂wᵢ

Training loop

  • Forward pass: compute predictions
  • Loss: measure error (MSE, CE…)
  • Backward pass: compute gradients
  • Update: w ← w − η · ∂L/∂w

Optimizers

  • SGD (+ momentum)
  • RMSProp
  • Adam ← default choice
  • AdamW (weight decay)

🖼️ Convolutional Neural Networks

Key ideas

  • Local connectivity: each neuron sees a small patch
  • Weight sharing: same filter across the image
  • Pooling: spatial downsampling
  • Translation invariance
Output size = ⌊(N − F + 2P) / S⌋ + 1

N=input, F=filter, P=padding, S=stride

Landmark architectures

  • LeNet-5 (1998)
  • AlexNet (2012) — ReLU, Dropout
  • VGG-16 (2014) — depth
  • ResNet (2015) — skip connections
  • EfficientNet (2019) — compound scaling
  • ConvNeXt (2022) — modernised CNN

🔮 Attention & Transformers

Self-attention allows every token to attend to every other token in the sequence — capturing long-range dependencies that RNNs struggle with.

Attention(Q, K, V) = softmax( QKᵀ / √dₖ ) · V

Transformer block

  • Multi-Head Self-Attention
  • Add & LayerNorm
  • Feed-Forward Network (FFN)
  • Add & LayerNorm

Applications

  • NLP: BERT, GPT, T5, LLaMA
  • Vision: ViT, DINO, SAM
  • Multimodal: CLIP, Flamingo, Gemini
  • Audio: Whisper, AudioLM

🎨 Generative Models

VAE

Encodes input into a distribution in latent space. Enables smooth interpolation and generation.

L = Lᵣₑ꜀ + β·KL(q‖p)

GAN

Generator vs. Discriminator adversarial game. Produces sharp, realistic samples.

min_G max_D V(D,G)

Diffusion

Learns to reverse a gradual noising process. State-of-the-art image & audio generation.

xₜ = √ᾱₜ x₀ + √(1−ᾱₜ) ε

Stable Diffusion · DALL·E 3 · Sora · MusicGen are all diffusion-based

⚙️ Training at Scale

Regularisation

  • Dropout: randomly zero activations
  • Batch Norm: normalise per mini-batch
  • Layer Norm: preferred in Transformers
  • Weight decay: L2 penalty on weights
  • Data augmentation

Practical tips

  • Start with a learning rate finder
  • Use mixed precision (fp16 / bf16)
  • Monitor train vs. val loss curves
  • Gradient clipping for stability
  • Cosine LR schedule + warmup

💡 Transfer learning — fine-tuning a pre-trained model — is almost always better than training from scratch when data is limited.

🐍 PyTorch Quickstart


import torch
import torch.nn as nn

# A simple 3-layer MLP
class MLP(nn.Module):
    def __init__(self, in_dim, hidden, out_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, hidden),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(hidden, hidden),
            nn.ReLU(),
            nn.Linear(hidden, out_dim),
        )

    def forward(self, x):
        return self.net(x)

model     = MLP(784, 256, 10).to("cuda")
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
criterion = nn.CrossEntropyLoss()
